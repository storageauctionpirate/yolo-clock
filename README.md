# YOLO: The Life Clock (working draft) — for Mike / Pirate
Single-file `index.html`, vanilla JS, localStorage only. All values (foods, minute rules, targets, badges) live in the `CONFIG` object at the top of the script.
Published to https://storageauctionpirate.github.io/yolo-clock/ via GitHub contents API (publish.sh).
Fun estimates, not medical advice.

## v2 (Oct 16 2026)
Per-serving food minutes from research (HENI, Stylianou 2021, plus others); new Habits tab (cravings beaten, activities, sun, salt, screens, sleep, cigarettes); ultra-processed foods take a penalty and whole foods get a small bonus; Sources tab. Backup of v1: index.backup-*.html

## v3 (Oct 16 2026)
Welcome form shown on first launch, plus a Me tab (profile, weight log, personal targets, starting life estimate). Growth chart. Fast-food section with typical portions.
v3b: added habit history (status, years, amount, quit date), heaviest weight, credit back for quitting smoking (Doll 2004), Since-you-quit counter.

Renamed Oct 16 2026: was Life Clock (life-clock), and before that Lifetime Clock (lifetime-clock). Both old URLs now redirect here. The localStorage key is still lifeClock.v1, so data carries over (same github.io origin).
